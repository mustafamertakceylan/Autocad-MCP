# Autocad MCP v1.2.0

### English

Windows x64 preview for **full AutoCAD2027** with mechanical drawing tools.
Version 1.1.0 was skipped.

- 60 typed MCP tools (52 in v1.0.0). Existing tool calls stay valid.
- ISO drawing profile in one step: lettering, line types and line groups,
  layers and dimension style.
- Native MLEADER notes; angular, arc length and ordinate dimensions;
  chain/baseline series; ISO notation around the live measured value and
  hole callouts. Written decimals and trailing zeros are kept exactly.
- Geometrical tolerancing: stacked ISO feature control frames with written
  values and modifiers, datum feature indicators, and general specification
  notes only for references the user selects.
- Drawing sheet A0–A4 with filing margin and centring marks, and a
  title block layout with a first/third angle projection symbol. Fields
  are filled only from the request; omitted fields stay empty.
- Black-only PDF via a monochrome plot style, justified text, free
  dimension text position, extrusion in front/side planes.

**Download:** `Autocad-MCP-1.2.0-Windows-x64.zip` and its SHA256 sidecar.
Extract everything; close AutoCAD; run `install.cmd`. Open AutoCAD,
then `Autocad MCP.cmd` and follow the setup guide. AutoCAD must already
be installed and separately licensed; users need no SDK, compiler or npm.
Installing over an earlier version keeps it as a rollback archive.

**UNSIGNED Windows preview:** ARX and desktop EXE are not code-signed.
Windows/AutoCAD may show publisher/trust prompts. The bundled Node
signature is verified. SHA256 detects changed bytes; it does not certify
the publisher. Separate clean-machine acceptance, real Windows reboot,
Explorer restart and real startup registration have not been completed.
This is not the fully signed/clean-device Phase6 acceptance.

Standards are referenced by number and implemented in our own words; no
standard text or table is included. AutoCAD LT and macOS packages are
unsupported. The app UI is Turkish. Live Claude model testing was not
run. Tool success does not certify engineering accuracy or production
readiness; tolerances, fits, surface, thread and weld values are never
invented and must come from the user.

### Türkçe

Makine teknik resmi araçlarıyla **tam AutoCAD2027** için Windows x64
önizlemesi. 1.1.0 sürüm numarası atlandı.

- 60 tipli MCP aracı (v1.0.0'da 52). Mevcut araç çağrıları geçerli kalır.
- Tek adımda ISO çizim profili: yazı, çizgi tipleri ve grupları, katmanlar
  ve ölçü stili.
- Native MLEADER notları; açısal, yay uzunluğu ve koordinat ölçüleri;
  zincir/taban seri ölçü; canlı ölçü değeri çevresinde ISO gösterimi ve
  delik notları. Yazılan ondalıklar ve sondaki sıfırlar aynen korunur.
- Geometrik tolerans: yazıldığı gibi değer ve değiştiricilerle üst üste
  ISO tolerans çerçeveleri, referans göstergesi ve yalnız kullanıcının
  seçtiği atıflarla genel şartname notu.
- Dosyalama payı ve merkezleme işaretli A0–A4 çizim kâğıdı; birinci/üçüncü
  açı sembollü antet. Alanlar yalnız istekten dolar, verilmeyenler boş kalır.
- Tek renk çizim stiliyle siyah PDF, hizalı yazı, serbest ölçü yazısı
  konumu, ön/yan düzlemde katı çekme.

**İndir:** `Autocad-MCP-1.2.0-Windows-x64.zip` ve SHA256 yan dosyası.
Tamamını aç; AutoCAD kapalıyken `install.cmd` çalıştır. AutoCAD'i,
ardından `Autocad MCP.cmd` dosyasını açıp kurulum rehberini izle.
AutoCAD ayrıca kurulu/lisanslı olmalıdır; SDK, derleyici veya npm gerekmez.
Önceki sürümün üzerine kurulumda eski sürüm geri alma arşivi olarak saklanır.

**Windows paketi imzasız önizlemedir:** ARX ve masaüstü EXE kod imzalı
değildir. Windows/AutoCAD yayıncı/güven uyarısı gösterebilir. Paket içi
Node imzası doğrulanır. SHA256 değişen byte'ları saptar, yayıncı kimliğini
belgelemez. Ayrı temiz bilgisayar kabulü, gerçek reboot, Explorer restart
ve gerçek başlangıç kaydı kontrolleri tamamlanmadı. Tam imzalı/temiz
cihaz Faz6 kabulü iddia edilmez.

Standartlara numarasıyla atıf yapılır ve kurallar kendi cümlelerimizle
uygulanır; standart metni veya tablosu içerilmez. AutoCAD LT ve Mac paketi
desteklenmez. Uygulama arayüzü Türkçedir. Canlı Claude model testi
çalıştırılmadı. Başarılı MCP işlemi mühendislik doğruluğu veya üretim
onayı değildir; tolerans, geçme, yüzey, diş ve kaynak değerleri
uydurulmaz, kullanıcıdan alınır.
