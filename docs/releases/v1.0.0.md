# Autocad MCP v1.0.0

### English

First public Windows x64 preview for **full AutoCAD2027**.

- 52 typed MCP tools for 2D geometry, real dimensions/annotations,
  blocks, solids, mechanical helpers, layouts/PDF, xrefs and batches.
- Local tray app with separate CAD/MCP status, explicit session
  selection, reconnect and optional startup in the tray.
- Numbered AutoCAD/MCP setup guides, client-specific instructions,
  copy buttons and an original red logo.
- Bundled Node24, per-user installation, upgrade, rollback and recovery.
- Codex desktop/CLI, Claude Code and OpenCode1.x setup and existing skills.
- Apache-2.0 source, English/Turkish READMEs and third-party notices.

**Download:** `Autocad-MCP-1.0.0-Windows-x64.zip` and its SHA256 sidecar.
Extract everything; close AutoCAD; run `install.cmd`. Open AutoCAD,
then `Autocad MCP.cmd` and follow the setup guide. AutoCAD must already
be installed and separately licensed; users need no SDK, compiler or npm.

**UNSIGNED Windows preview:** ARX and desktop EXE are not code-signed.
Windows/AutoCAD may show publisher/trust prompts. The bundled Node
signature is verified. SHA256 detects changed bytes; it does not certify
the publisher. Separate clean-machine acceptance, real Windows reboot,
Explorer restart and real startup registration have not been completed.
This is not the fully signed/clean-device Phase6 acceptance.

AutoCAD LT and macOS packages are unsupported in this release. The app
UI is currently Turkish. Live Claude model testing was not run. Tool
success does not certify engineering accuracy or production readiness.

### Türkçe

**Tam AutoCAD2027** için ilk public Windows x64 önizlemesi.

- 2B geometri, gerçek ölçü/teknik resim, blok, katı, mekanik yardımcılar,
  pafta/PDF, xref ve batch işlemleri için 52 tipli MCP aracı.
- Ayrı CAD/MCP durumu, açık oturum seçimi, yeniden bağlantı ve isteğe
  bağlı tepside başlangıç içeren yerel uygulama.
- Numaralı AutoCAD/MCP rehberi, istemci talimatları, kopyalama düğmeleri
  ve özgün kırmızı logo.
- Paket içi Node24, kullanıcıya özel kurulum, yükseltme, geri alma/kurtarma.
- Codex masaüstü/CLI, Claude Code, OpenCode1.x ayarları ve mevcut skill'ler.
- Apache-2.0 kaynak, İngilizce/Türkçe README ve üçüncü taraf bildirimleri.

**İndir:** `Autocad-MCP-1.0.0-Windows-x64.zip` ve SHA256 yan dosyası.
Tamamını aç; AutoCAD kapalıyken `install.cmd` çalıştır. AutoCAD'i,
ardından `Autocad MCP.cmd` dosyasını açıp kurulum rehberini izle.
AutoCAD ayrıca kurulu/lisanslı olmalıdır; SDK, derleyici veya npm gerekmez.

**Windows paketi imzasız önizlemedir:** ARX ve masaüstü EXE kod imzalı
değildir. Windows/AutoCAD yayıncı/güven uyarısı gösterebilir. Paket içi
Node imzası doğrulanır. SHA256 değişen byte'ları saptar, yayıncı kimliğini
belgelemez. Ayrı temiz bilgisayar kabulü, gerçek reboot, Explorer restart
ve gerçek başlangıç kaydı kontrolleri tamamlanmadı. Tam imzalı/temiz
cihaz Faz6 kabulü iddia edilmez.

Bu sürümde AutoCAD LT ve Mac paketi desteklenmez. Uygulama arayüzü
Türkçedir. Canlı Claude model testi çalıştırılmadı. Başarılı MCP işlemi
mühendislik doğruluğu veya üretim onayı değildir.
